Collections

backed by real XMR you still own
  • Drop it. Name, image, cap. Free signature.
  • Each item is a real XMR output you own — 0.001 XMR by default, creator sets it.
  • Proofs, not trust. Monero doesn't know it's an item; the xmrfun indexer verifies every mint and move on-chain.
  • Spend it from a normal wallet and the item burns.
